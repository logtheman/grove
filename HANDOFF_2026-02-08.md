# Grove Development Handoff - February 8, 2026

## Context
Working on Grove, a Tauri desktop app that combines a terminal with workspace management. The user works on remote Bento servers via SSH and needs Grove to support remote git worktrees.

## Progress Today

### ✅ What's Working
1. **Terminal**: Fully functional - renders correctly, handles input/output, supports SSH sessions
2. **Workspace Parsing**: Can paste `git worktree list --porcelain` output into the "+" input to add remote workspaces
3. **Workspace Display**: All parsed worktrees show in the sidebar with names and branches
4. **Selection & Removal**: Can click workspaces to select them and hover to remove them

### 🚧 What's Not Working

#### 1. **Scan Button** (High Priority)
**Problem**: Currently runs `git worktree list` on the local Mac filesystem, but user's repos are on remote Bento server.

**Current Code**: `src-tauri/src/ipc/commands.rs:210` - `scan_for_workspaces()`
- Runs local `git worktree list` via Rust Command
- Doesn't work for SSH sessions

**Solution Needed**:
- Send `git worktree list --porcelain` command to the active terminal
- Capture the output
- Parse and add worktrees
- OR: Track terminal CWD with OSC 7 (partially implemented in `src-tauri/src/pty/manager.rs`)

#### 2. **Right Panel Not Populating** (High Priority)
**Problem**: Clicking a workspace doesn't show details in the right panel.

**Investigation Needed**:
- Check `src/App.tsx` - what should happen when `handleSelectWorkspace` is called?
- Is there a right panel component that should display workspace details?
- What data should be shown? (files, git status, etc.)

#### 3. **Remote Git Integration** (Medium Priority)
**Problem**: Git status won't work for remote paths - all git operations run locally.

**Files to Check**:
- `src-tauri/src/git/status.rs` - runs local git commands
- `src-tauri/src/git/watcher.rs` - watches local filesystem

**Solution Needed**:
- Run git commands through the terminal for remote workspaces
- Flag workspaces as "remote" vs "local"
- Use different code paths for remote git operations
